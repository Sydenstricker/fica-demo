# FICA — demonstração

Build estático do **FICA** (*Framework de Intervenção Cognitiva Adaptativa*),
para abrir e usar sem instalar nada.

> ⚠️ **É uma demonstração.** As chamadas ao modelo de linguagem estão
> desligadas: ao conversar com um agente, a resposta é um aviso dizendo isso.
> Todo o resto — tutorial, gamificação, Árvore de Habilidades e a
> fundamentação teórica — funciona.

## Por onde começar

1. O **tutorial introdutório** abre sozinho. São cerca de 11 passos e vale
   percorrer: `🎓 Tutoriais` fica **trancado** até ele terminar.
2. Depois, em **Tutoriais → Fundamentos**, está o *"Por que o FICA é assim"* —
   a fundamentação teórica do produto, com as fontes de cada afirmação.
3. A **Árvore de Habilidades** destrava no primeiro marco cognitivo.

## O que este repositório é, e o que não é

Só o resultado do build. O código-fonte, os registros de decisão e os dados
da bancada de medição vivem no repositório do projeto, que é separado.
